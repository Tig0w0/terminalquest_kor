앞으로 TerminalQuest에서 만날 과제들은 소프트웨어 개발 도구를 다운로드하고, 컴퓨터에서 직접 작성한 코드를 실행하는 과정을 안내합니다. 신나겠죠?!

물론 신나는 일이지만, 소프트웨어 개발을 시작할 때 알아 두어야 할 몇 가지 안전 수칙이 있습니다. 아래 내용을 모두 읽고 오른쪽 질문에 답한 다음 *HACK*을 클릭하세요. 그러면 TerminalQuest를 시작할 준비도 끝나고, 소화기로 라이언을 구할 수도 있습니다!

## 코딩하기 전에 알아두기

<details>
<summary>다운로드하고 설치할 때 주의하세요</summary>

소프트웨어 개발 도구와 서드 파티 소프트웨어 라이브러리(third-party software library, 나중에 배우게 됩니다)는 컴퓨터에 저장된 데이터나 웹 브라우저를 통해 이용하는 데이터에 폭넓게 접근할 수 있습니다. 반드시 신뢰할 수 있는 출처에서만 소프트웨어를 다운로드하고 설치하세요!
</details>

<details>
<summary>복사해서 붙여 넣기 전에 확인하세요</summary>

개발자라면 누구나 인터넷에서 찾은 코드 예제를 복사해 붙여 넣곤 하지만, 이때도 주의해야 합니다. 어떤 명령어나 코드가 무슨 일을 하는지 모른다면 신뢰할 수 있는 멘토나 선생님에게 질문하세요. 코드를 실행하면 보통 그 코드는 컴퓨터 사용자인 여러분이 할 수 있는 일 대부분을 수행할 수 있습니다. 개인 파일과 데이터에 접근하는 일도 포함됩니다.
</details>

<details>
<summary>코드 속 민감한 데이터를 살펴보세요</summary>

소프트웨어 개발자로 성장하면서 여러분과 여러분의 코드는 여러 종류의 민감한 데이터를 다루게 됩니다. 여기에는 자신이나 다른 사람의 이메일 주소, 전화번호와 같은 개인 정보가 포함됩니다. 코드에서 개인 데이터를 다룰 때마다 그 정보가 어디에, 어떤 방식으로 저장되고 접근되는지 생각해 보세요. 데이터를 코드 파일에 저장하고 있나요? 그렇다면 누가 그 코드 파일에 접근할 수 있나요? [GitHub](https://github.com) 같은 코드 공유 서비스나 다른 파일 공유 시스템을 통해 의도치 않게 다른 사람에게 공개될 가능성은 없나요?

데이터를 다룰 때 이런 질문을 스스로 던지는 습관은 여러분과 사용자를 안전하게 지켜 줍니다.
</details>
