# 괄호 균형 맞추기

<div class="aside"><h3>요구 사항</h3><ul>
  <li>`balanceBrackets` 함수를 만드세요.</li>
  <li>`[`, `]`, `(`, `)`, `{`, `}`로 이루어진 배열을 받습니다.</li>
  <li>괄호의 짝과 순서가 맞으면 `true`, 아니면 `false`를 반환하세요.</li>
  <li>빈 배열에는 `true`를 반환하세요.</li>
  <li>완료하면 <em>해킹</em>을 누르세요.</li>
</ul></div>

이 단말기는 동력 발생기의 연료 혼합물이 균형을 이루는지 확인합니다. 괄호 배열을 받아 균형 여부를 불리언으로 반환하는 `balanceBrackets` 함수를 만드세요.

## 예제

- `["{", "}"]` → `true`
- `["[", "(", "]", ")"]` → `false`
- `[]` → `true`
- `["{", "[", "}"]` → `false`
- `["]", "(", ")", "["]` → `false`
- `["(", ")", "[", "(", "{", "}", ")", "]"]` → `true`
