# 숫자 배열의 합

<div class="aside"><h3>요구 사항</h3><ul>
  <li>`sumArray` 함수를 만드세요.</li>
  <li>이 함수는 숫자 배열을 받습니다.</li>
  <li>빈 배열이면 `0`을 반환하세요.</li>
  <li>모든 숫자를 더한 합계를 반환하세요.</li>
  <li>완료하면 <em>해킹</em>을 누르세요.</li>
</ul></div>

이 단말기는 생산된 어둠의 덕타이피움의 총질량을 계산합니다. 숫자 배열을 받아 모든 값을 더한 결과를 반환하는 `sumArray` 함수를 만드세요.

## 예제

- `[1, 2, 3]` → `6`
- `[-1, 0, 1]` → `0`
- `[2.5, 5]` → `7.5`
- `[]` → `0`
