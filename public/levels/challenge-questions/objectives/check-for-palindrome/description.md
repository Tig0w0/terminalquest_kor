# 회문 확인하기

<div class="aside"><h3>요구 사항</h3><ul>
  <li>`isPalindrome` 함수를 만드세요.</li>
  <li>문자열을 받아 앞뒤 어느 방향으로 읽어도 같으면 `true`, 아니면 `false`를 반환하세요.</li>
  <li>빈 문자열이나 한 글자 문자열에는 `true`를 반환하세요.</li>
  <li>완료하면 <em>해킹</em>을 누르세요.</li>
</ul></div>

이 단말기는 시스템을 지나는 신호를 안정화해 대장간에 순수한 회문 동력을 계속 공급합니다. 문자열을 소문자로 바꾸고 공백을 제거한 뒤 회문인지 판단하는 `isPalindrome` 함수를 만드세요.

[회문 위키 문서](https://en.wikipedia.org/wiki/Palindrome)도 참고할 수 있습니다.

## 예제

- `tacocat` → `true`
- `""` → `true`
- `heLLo` → `false`
- `Never odd or even` → `true`
