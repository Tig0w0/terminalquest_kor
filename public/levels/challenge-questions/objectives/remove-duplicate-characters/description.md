# 연속 중복 문자 제거하기

<div class="aside">
<h3>요구 사항</h3>
<ul>
  <li>`removeDuplicateCharacters` 함수를 만드세요.</li>
  <li>이 함수는 문자열을 받습니다.</li>
  <li>연속해서 반복되는 문자를 하나로 줄인 새 문자열을 반환하세요.</li>
  <li>완료하면 <em>해킹</em>을 누르세요.</li>
</ul>
</div>

이 단말기는 덕타이피움을 어둡게 만드는 명령 순서가 고유한지 확인합니다. 문자열을 받아 연속 중복 문자를 하나로 줄이는 `removeDuplicateCharacters` 함수를 만드세요.

## 예제

- `aabbcc` → `abc`
- `xyyx` → `xyx`
- `aaaaaaaaaaaaaaabc` → `abc`

함수를 작성한 뒤 _해킹_ 버튼을 누르세요!
