# 웹의 작동 원리

여러분 앞의 과제는 API 아카데미의 네 학생 기숙사를 위한 **지식 상자**를 하나씩 여는 것입니다. 이 상자는 수학자 [에이다 러브레이스(Ada Lovelace)](https://en.wikipedia.org/wiki/Ada_Lovelace)의 이름을 딴 **러브레이스 기숙사**가 마련했습니다. 잠금장치를 우회하려면 웹의 작동 원리에 관한 질문에 답해야 합니다. 오른쪽 질문에 답하고 *HACK*을 클릭하세요.

## API 학습하기

API 아카데미의 과제는 포그 아울 승무원 **크레이그 데니스**가 진행하는 [훌륭한 API 입문 강좌](https://www.youtube.com/watch?v=GZvSYJDk-us)를 바탕으로 합니다. 아래의 *도움말 보기* 버튼을 클릭하면 질문과 관련된 영상 구간을 볼 수 있습니다.
