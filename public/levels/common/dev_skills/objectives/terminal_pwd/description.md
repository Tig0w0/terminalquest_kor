# 이제 당신이 명령할 차례입니다

<div class="aside">
<h3>할 일</h3>
<ul>
  <li><b>명령줄 인터페이스(CLI)</b>를 여세요. Mac/Linux에서는 <code>Terminal</code>, Windows에서는 <code>PowerShell</code>을 실행합니다.</li>
  <li><code>pwd</code> 명령어를 입력하고 Enter 키를 눌러 실행하세요.</li>
  <li>명령어 출력의 <b>마지막 줄만</b> 오른쪽 입력란에 붙여 넣은 다음 <em>HACK</em>을 클릭하세요.</li>

시뮬레이션에 들어서자 공중에 떠 있는 발판들이 보입니다. 발판 사이를 건널 만한 길은 어디에도 보이지 않습니다. 한 발판 위에는 상자가 놓여 있습니다. **이 구역의 깃발이 분명 저 안에 있을 겁니다!**

용감하게 심연으로 발을 내디뎠지만, 놀랍게도 추락하지 않았습니다! 허공을 걸어 다음 발판으로 향하던 당신 앞을 레이저 장벽이 가로막습니다. 이 구역의 장벽은 각각 특정 프로그래밍 능력을 시험하도록 설계되어 있습니다.

장벽을 해제하려면 [명령줄 인터페이스(command line interface)](https://techterms.com/definition/command_line_interface), 줄여서 **CLI**를 기본적으로 다룰 수 있다는 것을 증명해야 합니다. **컴퓨터에 이미 설치된** CLI 앱을 여세요. Mac과 많은 Linux 계열 시스템에서는 [Terminal](https://support.apple.com/guide/terminal/welcome/mac), Windows에서는 [PowerShell](https://docs.microsoft.com/en-us/powershell/scripting/install/installing-windows-powershell?view=powershell-7)을 사용합니다.

CLI 앱이 열리면 다음의 간단한 명령어를 입력하세요.

```bash
pwd
```

그런 다음 키보드의 **Enter 키를 눌러** 명령어를 실행하세요. 이 명령어는 CLI의 **현재 작업 디렉터리(present working directory)**를 출력합니다. 자세한 설명은 `도움말` 탭에서 볼 수 있습니다.

출력 결과의 **마지막 줄**을 오른쪽 입력란에 붙여 넣으세요. 다 했다면 *HACK*을 클릭해 답을 확인하고 장벽을 해제하세요!
