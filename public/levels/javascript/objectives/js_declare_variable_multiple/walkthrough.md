# 변수 생성 추가 연습

[변수(variable) 생성하기](https://javascript.info/variables)를 조금 더 연습해 볼 시간입니다!

이번에는 JavaScript에서 흔히 쓰이는 [데이터 타입(data types)](https://developer.mozilla.org/ko/docs/Web/JavaScript/Data_structures)들을 사용하여 **세 개의 변수를 선언**해야 합니다. 이러한 데이터 타입들에 대해서는 연구소를 더 진행하면서 자세히 배우게 될 것입니다.

이 과제를 완료하려면 코드 폴더 안에 `chestConfiguration.js`라는 이름의 파일을 생성해야 합니다. 여러분의 코드 폴더 위치는 다음과 같습니다:

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

이 파일 안에서 과제(개요) 탭에 설명된 이름과 값을 가진 세 개의 변수를 선언하세요. 아래 코드는 다른 이름과 값을 가진 변수들을 선언하는 예시입니다. 참고용으로 활용하실 수는 있지만, 변수 이름과 값을 직접 바꾸어 작성해야만 합니다:

```js
const mulletLooksGood = false;
const meaningOfLife = 42;
const bestCharacter = 'Baby Yoda';

console.log('Mullets look good? ' + mulletLooksGood);
console.log('The meaning of life is: ' + meaningOfLife);
console.log('My favorite character in Star Wars is: ' + bestCharacter);
```

과제 탭의 지시대로 변수를 올바르게 선언했다면, *HACK* 버튼을 클릭하세요.
