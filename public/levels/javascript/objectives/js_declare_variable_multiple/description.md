여러분과 같은 TwilioQuest 프로그램의 오퍼레이터들을 위해 준비된 보급품 상자를 발견했습니다. 원래라면 누구나 자유롭게 이용할 수 있어야 하지만, 지금은 굳게 잠겨 있습니다. 이 보급품을 얻으려면 **앞서 사용했던 보안 설정 덮어쓰기(override) 방법**을 사용해야 합니다.

여러분의 코드 폴더 안에 `chestConfiguration.js`라는 이름의 파일을 생성하세요. 이 상자의 보안 설정을 덮어쓰기 위해 파일 안에 다음 세 개의 변수를 선언해 주세요:

| 변수 이름 | 값 |
| ------------- | ----- |
| `verifiedUser` | [불리언(boolean)](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Boolean) 값 `true` |
| `accessLevel` | [숫자(number)](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Number) 값 `7` |
| `favoriteRobot` | [문자열(string)](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/String) 값 `Cedric` |

코드 작성을 마쳤다면, *HACK* 버튼을 클릭하여 작업한 코드를 검사받고 보안 장벽의 레이저 설정을 덮어쓰세요.
