# 컴퓨터에 Node.js 설치하기

연구소에 들어가기 전에 표준 보안 검사를 통과해야 합니다. 컴퓨터의 터미널에서 **JavaScript 프로그램을 실행**하는 데 필요한 소프트웨어가 설치되어 있음을 증명하세요.

가장 최신 Node.js 릴리스를 [다운로드하여 설치](https://www.nodejs.org)하세요. 설치를 마치면 PowerShell이나 터미널에서 `node` 명령어를 사용할 수 있습니다.

컴퓨터에 설치된 `node` 명령어의 **전체 경로**를 붙여 넣으세요. 찾는 방법을 모르겠다면 도움말을 확인하세요. 오른쪽 입력란에 경로를 붙여 넣고 *해킹* 버튼을 누르세요.
