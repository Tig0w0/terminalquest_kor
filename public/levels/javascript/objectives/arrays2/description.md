에어록의 두 번째 문 역시 또 다른 보안 장벽에 의해 가로막혀 있습니다. 이곳에서 여러분이 고쳐야 할 JavaScript 코드는 화물 명세서를 처리하는 함수입니다 - 구체적으로 말하면, 문자열 배열을 인수로 받아서 배열의 첫 번째 항목과 마지막 항목을 하나로 붙인 새로운 문자열을 반환하는 함수가 필요합니다.

**Infinite Loop** 호에 탑승하기 전에 이 함수가 제대로 작동하도록 고쳐야 합니다.

코드 폴더에 `addFirstToLast.js`라는 이름의 파일을 만드세요. 그 안에 파일 이름과 동일한 `addFirstToLast`라는 이름의 함수를 정의하세요. 이 함수는 단 하나의 인수, 즉 문자열 배열을 받아야 합니다.

여러분의 함수는 입력 배열의 첫 번째와 마지막 항목을 서로 연결한 문자열을 반환해야 합니다. 시작 코드로 사용할 수 있는 예시가 "도움말(Help)" 탭에 제공되어 있습니다.

입력과 출력의 몇 가지 예시는 다음과 같습니다:

| 입력(Input)                        | 출력(Output)           |
| ---------------------------- | ---------------- |
| ['first', 'second', 'third'] | 'firstthird'     |
| ['golden', 'terrier']        | 'goldenterrier'  |
| ['cheerio']                  | 'cheeriocheerio' |
| [ ]                           | ''               |

여러분의 코드가 위 설명처럼 배열을 처리할 수 있게 되면, _HACK_ 버튼을 클릭하여 앞으로 전진하세요!
