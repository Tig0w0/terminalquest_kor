# 비밀번호 인덱스 찾기

이번 마지막 과제를 풀기 위해서는 2차원 배열(two-dimensional array)의 데이터를 다루는 방법을 배워야 합니다. 이러한 객체 타입은 그리드(격자) 안의 점이나 체스판 위의 말처럼 2차원 공간에 존재하는 정보를 표현할 때 자주 사용됩니다.

일반적인 배열과 마찬가지로, 여러분은 **구독(subscript) 표기법** (대괄호 표기법)을 사용하여 데이터에 접근합니다.

1차원 배열에서는 단 하나의 인덱스 번호만 존재합니다. 다음 배열을 생각해보세요.

```js
const animals = ['dog', 'cat', 'bird'];
```

배열의 두 번째 위치에 있는 `cat`이라는 값은 `animals[1]`을 통해 찾을 수 있습니다.

2차원 배열에서는 문자열이나 숫자 대신 **배열들로 이루어진 배열**을 다루게 됩니다. 선 위의 X/Y 좌표들이라고 생각할 수 있는 다음 배열을 살펴보세요:

```js
const points = [ [0,1], [1,2], [2,3] ];
```

`points` 배열의 '인덱스 0' 위치에 있는 값은 `[0,1]`이라는 또 다른 배열입니다. 즉 `points[0]`은 `[0,1]`과 같습니다. `points[0]` 역시 배열이기 때문에, 그 안에 있는 값에 접근할 때도 인덱스를 사용할 수 있습니다. 이 예제에서 `points[0][1]`은 `1`이 됩니다. 이는 `points` 배열 안에 있는 첫 번째 배열의 두 번째 요소라는 뜻입니다.

이를 이해하는 가장 쉬운 방법은 2차원 배열의 첫 번째 숫자를 "행(row)"으로, 두 번째 숫자를 "열(column)"로 생각하는 것입니다. 배열을 보기 좋게 정렬해 보면 이를 한눈에 알아볼 수 있습니다 (이런 식의 코드 줄바꿈이 객체의 실제 값을 바꾸지는 않습니다):

```js
const points = [ 
  [0, 1], 
  [1, 2], 
  [2, 3] 
];
```

이제 2차원 배열의 데이터에 접근하는 기본적인 개념을 알게 되었습니다. 오른쪽의 질문에 답한 뒤 _HACK_ 버튼을 누르세요. 과제(Objective) 탭에 있는 2차원 배열의 데이터를 사용해야 합니다 (위의 예제 코드가 아닙니다!).
