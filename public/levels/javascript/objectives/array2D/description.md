**Infinite Loop** 호의 안전한 화물칸 중 한 곳에서, 여러분은 TwilioQuest 프로그램의 전기 엔지니어에게 접근하기 위해 해제해야 할 보안 노드 하나를 발견합니다.

이 노드는 현재 2개의 환경 변수가 잘못 구성되어 있어 잠겨 있는 상태인데, 이 변수들은 **2차원 배열(two-dimensional array)** 안에 들어있습니다.

이 노드를 해킹하고 **Infinite Loop**의 마스터 암호를 찾는 데 필요한 잃어버린 인덱스를 되찾으려면, 해당 변수들에 알맞은 값을 지정해야 합니다.

## 2차원 배열 이해하기

이 과제를 해결하기 위해 다음의 [2차원 배열](https://medium.com/javascript-in-plain-english/javascript-multi-dimensional-arrays-7186e8edd03)을 살펴보세요.

```js
const twoDimensionalArray = [
  ['dogs', 'cats', 'zebras'],
  ['pizza', 'tacos', 'kale'],
  ['baseball', 'football', 'hockey']
];
```

오른쪽의 입력란에서는 서로 다른 두 개의 인덱스 위치에 어떤 값이 있는지 묻고 있습니다. 그 값이 무엇인지 알아냈다면, 알맞은 칸에 값을 입력하고 _HACK_ 버튼을 누르세요.
