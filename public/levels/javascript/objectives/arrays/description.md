당신은 연구소의 동쪽 구역(east wing)에 진입합니다. 이곳은 화물 수송선들이 사용하는 에어록(airlock) 구역으로 보입니다. 연구소 폭발 사고가 발생했을 때 **연구팀의 엔지니어**가 보급선에 갇힌 것이 틀림없습니다!

최근 화물 명세서를 스캔해 보니, 현재 정거장에 도킹된 화물선의 이름은 **Infinite Loop**(무한 루프)입니다. 이 화물선의 시스템은 아이템들의 목록, 즉 [배열(arrays)](https://ko.javascript.info/array)을 사용하는 JavaScript 논리로 구동되고 있습니다. 여러분 앞길을 가로막는 제어 장치들을 해제하려면 배열을 다양하게 활용하는 JavaScript 코드를 작성해야 합니다.

## 상황 파악(Inventory)하기

**Infinite Loop** 호의 화물 목록이 실수로 지워진 뒤 이 레이저 장벽이 작동하기 시작했습니다. 앞으로 더 나아가려면 이를 고쳐야 합니다.

코드 폴더에 `freighterInventory.js`라는 이름의 파일을 만드세요. 이 파일 안에 `inventory`라는 이름의 변수를 선언하세요. 이 변수는 다음 5개의 [문자열(strings)](https://ko.javascript.info/string)이 순서대로 들어 있는 배열을 포함해야 합니다:

- `"Ducktypium Ore"`
- `"Uranium Rod"`
- `"Ruthenium Isotopes"`
- `"Concave Lens"`
- `"Refraction Panel"`

위의 아이템들이 포함된 `inventory` 변수를 코드로 성공적으로 만들었다면, _HACK_ 버튼을 클릭하세요.
