# 과제 도움말

이 구역의 모든 도전 과제를 해결하려면 [배열(arrays)](https://ko.javascript.info/array)의 개념을 마스터해야 합니다. 배열은 특정한 순서를 가진 객체(아이템)들의 목록입니다. [MDN의 배열 참고 문서에서 자세한 내용을 확인해 보세요](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Array).

이 과제를 완수하려면 코드 폴더에 `freighterInventory.js`라는 이름의 파일을 만드세요. 코드 폴더 위치는 다음과 같습니다:

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

`freighterInventory.js` 파일 안에, 과제 설명에 명시된 대로 `inventory`라는 이름의 배열 변수를 선언해야 합니다. 이 배열은 이전 탭에 나열된 것과 정확히 같은 순서로 5개의 문자열을 담고 있어야 합니다. 작성을 완료했다면 _HACK_ 버튼을 클릭하여 검증하세요!
