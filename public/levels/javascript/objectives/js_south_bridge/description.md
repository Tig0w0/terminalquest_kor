식물학 연구소의 남동쪽 구석에 숨겨져 있는 또 다른 시스템도 덕타이피움 사고 중에 손상된 것을 발견했습니다. 자동 스프링클러 시스템이 오프라인 상태가 되었고, 이로 인해 어떻게 된 일인지 **남쪽 다리(south bridge)**까지 비활성화되어 버렸습니다.

식물들에게 수분을 공급하고 남쪽 다리를 펼치려면, 자동 스프링클러 시스템을 고쳐야 합니다.

## 비 내리기

스프링클러 시스템을 점검해 보니 조건 논리(boolean logic)에 또 다른 문제가 있는 것으로 드러났습니다. 이를 해결하기 위해 코드 폴더에 `shouldWater.js`라는 이름의 파일을 만드세요. 이 스크립트는 **두 개의 명령줄 인수**를 받을 것이며, 둘 다 숫자입니다.

* 첫 번째 인수는 식물의 생명 상태를 나타냅니다 - `0`은 식물이 살아있음을 의미합니다.
* 두 번째 인수는 식물의 건조 수치를 나타냅니다 - `10`보다 높은 값은 식물에 물이 필요함을 뜻합니다.

살아있는 식물(상태 `0`)이면서 건조 수치가 `20`일 때, 이 스크립트를 실행하는 예시는 다음과 같습니다:

```bash
node shouldWater.js 0 20
```

스프링클러 시스템을 정상적으로 작동시키려면, 이 스크립트는 첫 번째 인수가 `0`이고 두 번째 인수가 `10`보다 큰 숫자인 경우에만 `WATER`라는 문자열을 출력해야 합니다. 그 외의 경우에는 아무것도 출력하지 않아야 합니다.

여러분의 코드가 위 설명대로 작동한다면, _HACK_ 버튼을 클릭하여 스프링클러를 고치세요!
