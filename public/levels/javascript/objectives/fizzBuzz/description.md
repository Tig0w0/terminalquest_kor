식물학 연구소의 거의 텅 빈 구역에서 먼지 쌓인 낡은 상자를 발견했습니다. 오랫동안 열린 적이 없는 듯해 안에 무엇이 들었는지 궁금해집니다.

잠금장치를 살펴보니 내부 판정 로직이 손상된 것 같습니다. 제대로 작동하는 프로그램으로 교체하면 열 수 있을 것입니다.

## 상자 잠금장치 고치기

코드 폴더에 `fizzBuzz.js` 파일을 만드세요. 프로그램은 정수 하나를 명령줄 인수로 받아야 합니다.

```bash
node fizzBuzz.js 15
```

| 입력 숫자 | 출력 값 |
| --- | --- |
| 3으로 나누어떨어짐 | `Java` |
| 5로 나누어떨어짐 | `Script` |
| 3과 5 모두로 나누어떨어짐 | `JavaScript` |
| 3과 5 어느 쪽으로도 나누어떨어지지 않음 | 입력 숫자 |

- 인수가 `3`이면 `Java`
- 인수가 `5`이면 `Script`
- 인수가 `15`이면 `JavaScript`
- 인수가 `7`이면 `7`

프로그램이 위와 같이 작동하면 *해킹* 버튼을 누르세요!
