식물학자와 여러분 사이를 가로막고 있는 마지막 다리 역시 비활성화되어 있습니다. 서쪽 다리와 마찬가지로 이 다리 역시 **나무 생명 탐지기(Tree Life Detector)**의 설정이 제대로 되어있지 않아 작동이 멈췄습니다.

이번에는 다리를 확장하기 위해 좀 더 향상된 버전의 나무 생명 탐지기 스크립트를 작성해야 합니다.

## 향상된 나무 생명 탐지기

코드 폴더에 `enhancedLifeDetector.js`라는 이름의 파일을 만드세요. 이 프로그램은 단 하나의 **명령줄 인수**를 받습니다 - 현재 나무의 생명 상태를 나타내는 한 자리 `Number`(숫자)입니다. 이 스크립트는 입력받은 숫자에 따라 나무의 현재 상태를 나타내는, 사람이 읽을 수 있는 문자열을 출력해야 합니다.

근처를 살펴보니, 나무의 생명 상태 ID와 사람이 읽을 수 있는 문자열의 매핑표가 이전보다 더 상세하게 적혀 있습니다 (`alive`와 `other` 외에도 다른 상태들이 존재합니다):

| 생명 상태 ID(Tree Life Status ID) | 나무 상태(Tree Status) |
| ------------------- | ----------- |
| 0 | "alive" |
| 1 | "flowering" |
| 2 | "shedding" |
| 3 이상 | "other" |

여러분의 스크립트가 실행될 때, 전달받은 ID 숫자를 바탕으로 알맞은 문자열 텍스트를 출력해야 합니다.

스크립트가 다음과 같이 실행될 경우:

```bash
node enhancedLifeDetector.js 2
```

`shedding`이라는 문자열을 출력해야 합니다. 만약 전달된 숫자가 0, 1, 2가 아니라면 스크립트는 `other`를 출력해야 합니다.

이 도전 과제를 완수하려면 이전에 사용했던 것보다 더 복잡한 조건 논리를 사용해야 합니다. 자세한 내용은 **도움말(Help)** 탭을 확인하세요.

여러분의 `enhancedLifeDetector.js` 스크립트가 이와 같이 정상 동작한다면, _HACK_ 버튼을 클릭하여 수리 작업을 검증받으세요!
