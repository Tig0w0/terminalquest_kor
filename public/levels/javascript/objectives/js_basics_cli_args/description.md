이 장벽 너머로 수석 과학자의 책상 위에 서류 더미가 쌓여 있는 것이 보입니다. 그 안에 여러분이 찾고 있는 비밀번호가 분명히 있을 것입니다. 과학자들이 덕타이피움(ducktypium) 실험을 계속할 수 있도록 도울 핵심 정보가 코앞에 있습니다!

여러분은 이 장벽이 닫힌 채로 열리지 않는 원인을 재빨리 찾아냈습니다. 바로 핵심 수학 계산을 수행할 **스크립트가 하나 누락**되었기 때문입니다.

코드 폴더 안에 `divideByTwo.js`라는 이름의 파일을 생성하세요. 여러분이 지금까지 작성했던 다른 스크립트들과 달리, 이 스크립트는 실행할 때 다음과 같이 **명령줄 인수(command line argument)**를 받아야 합니다:

```bash
node divideByTwo.js 48
```

이 스크립트는 전달받은 숫자를 가져와서 2로 나눈 다음, `console.log`를 사용해 결과를 출력해야 합니다. 이 과제는 조금 어렵기 때문에, 혹시 도움이 필요하다면 '도움말' 탭에 있는 **시작 코드로 활용할 수 있는 예제 코드**를 참고하세요.

코드 작성을 마쳤다면, *HACK* 버튼을 클릭하여 레이저 명령 함수를 덮어쓰세요.
