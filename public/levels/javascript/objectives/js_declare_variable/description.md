수석 과학자의 사무실로 가는 길을 가로막는 또 다른 장벽을 만났습니다. 조사해 보니, 이 장벽은 레이저 울타리를 "ON" 상태로 고정시키는 JavaScript 코드로 설정되어 있었습니다. 장벽을 해제하려면 **여러분이 직접 작성한 JavaScript 코드로 이 설정을 덮어써야(override) 합니다**.

여러분의 코드 폴더 안에 `laserConfiguration.js`라는 파일을 생성하세요. 이 파일 안에서 `laserStatus`라는 이름의 [변수(variable)](https://ko.wikipedia.org/wiki/%EB%B3%80%EC%88%98_(%EC%BB%B4%ED%93%A8%ED%84%B0_%EA%B3%BC%ED%95%99))를 선언하고, 그 값을 `OFF`라는 [문자열(string)](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/String) 값으로 설정하세요.

코드 작성을 마쳤다면, *HACK* 버튼을 클릭하여 작업한 코드를 검사받고 이 보안 장벽의 레이저 설정을 덮어쓰세요.
