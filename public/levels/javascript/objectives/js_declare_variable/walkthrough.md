# JavaScript에서 변수(variable) 생성하기

이 과제의 목표는 JavaScript 코드에서 [변수(variable)를 생성하는 방법](https://javascript.info/variables)을 연습하는 것입니다. 변수는 숫자, 텍스트, 그리고 더 복잡한 데이터 등 프로그램이 처리할 수 있는 다양한 종류의 데이터를 담는 그릇 역할을 합니다. 변수를 생성하고 나면 코드 내에서 변수 이름을 사용하여 해당 데이터를 참조할 수 있습니다.

이 과제를 완료하려면 코드 폴더 안에 `laserConfiguration.js`라는 이름의 파일을 생성해야 합니다. 여러분의 코드 폴더 위치는 다음과 같습니다:

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

이 파일 안에서 과제(개요) 탭에 설명된 이름과 값을 가진 변수를 선언하세요. 아래 코드는 다른 이름과 값을 가진 변수를 생성하는 예시입니다. 참고용으로 활용하실 수는 있지만, 그대로 복사/붙여넣기 할 경우 검증에 실패하게 됩니다:

```js
const favoriteRobot = 'Cedric';
console.log('My favorite robot is ' + favoriteRobot);
```

과제 탭의 지시대로 변수를 올바르게 선언했다면, *HACK* 버튼을 클릭하세요.
