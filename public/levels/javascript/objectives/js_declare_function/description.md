사고 현장의 잔해 한가운데서 연구소 내부 구역을 가로막고 있는 새로운 보안 장벽을 발견합니다.

이 장벽의 보안 시스템을 조사해 보니, 레이저 장벽이 `"ON"`인지 `"OFF"`인지를 결정하는 **JavaScript 함수(function)**로 구동되고 있음을 알아냅니다. 레이저 장벽을 무력화하려면 이 **함수를 덮어써야(override)** 합니다.

코드 폴더에 `laserFunction.js`라는 이름의 파일을 만드세요. 이 파일 안에 `getLaserSetting`이라는 이름의 [JavaScript 함수를 생성](https://developer.mozilla.org/ko/docs/Web/JavaScript/Guide/Functions)하세요. 이 함수는 값이 `"OFF"`인 [문자열(string)](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/String) 객체를 **반환(return)**해야 합니다.

코드가 준비되면 _HACK_ 버튼을 클릭하여 레이저 명령 함수를 덮어쓰세요.
