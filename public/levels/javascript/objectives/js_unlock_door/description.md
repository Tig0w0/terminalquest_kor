장벽을 살펴보니 JavaScript 연구소의 IT 부서에서만 잠금을 해제할 수 있는 것 같습니다. IT 부서에 전화하여 '글렌(Glen)'이라는 기술자와 통화합니다. 글렌은 마지못해 장벽을 해제해 주겠다고 동의했지만, 한 가지 조건이 있습니다. 바로 **친절하게 부탁해야 한다는 것**입니다.

계속 진행하려면 글렌에게 장벽을 열어달라고 (친절하게) 부탁하는 **JavaScript 프로그램을 작성해야 합니다**. 앞서 만들었던 폴더 안에 `sayPlease.js`라는 이름의 새 JavaScript 파일을 만드세요. 참고로, 여러분이 만들었던 폴더 경로는 다음과 같습니다:

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

`sayPlease.js` 파일 안에 다음 JavaScript 코드 한 줄을 복사해 넣으세요:

```js
console.log('Glen, will you please open the barrier?');
```

이 친절한 부탁 메시지를 출력할 코드를 작성하고 테스트를 마쳤다면, *HACK* 버튼을 클릭하세요. 부디 글렌이 여러분의 정중한 부탁을 받아주길 바랍니다.
