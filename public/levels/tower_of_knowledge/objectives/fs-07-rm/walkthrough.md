# 파일 삭제하기

`rm` 뒤에 파일 경로를 입력하면 파일을 삭제할 수 있습니다. 파일과 같은 폴더에 있다면 이름만 입력해도 됩니다. 예: `rm yourfilename.txt`

## 여러 파일 삭제하기

`rm firstfile.txt secondfile.txt`처럼 파일을 나열하면 한 명령어로 여러 파일을 삭제할 수 있습니다. `*` "와일드카드"로 파일 이름 패턴을 지정하여 일치하는 파일을 모두 삭제할 수도 있습니다.

예를 들어 폴더의 `.jpg` 이미지를 모두 삭제하려면 `rm *.jpg`를 입력합니다. `*.jpg`는 "`.jpg`로 끝나는 모든 것"이라는 뜻이므로 나머지 파일 이름과 관계없이 일치하는 이미지가 모두 삭제됩니다.

다음 과제에서는 폴더와 파일이 든 폴더를 삭제하는 방법을 배우게 됩니다.
