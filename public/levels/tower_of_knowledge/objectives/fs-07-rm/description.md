# 파일 삭제하기

<div class="aside">
<h3>요구 사항</h3>
<ul>
  <li><b>rm</b>으로 파일을 삭제하세요.</li>
  <li>완료하면 <em>해킹</em>을 누르세요.</li>
</ul>
</div>

파일을 만들 수 있게 되었으니 삭제하는 방법을 배워 봅시다!

이전 과제에서 만든 파일을 `rm`, 즉 "remove" 명령어로 삭제합니다. 터미널에서 `rm` 뒤에 삭제할 파일의 경로를 입력하세요.

```bash
$ ls
l33tcode.txt

$ rm l33tcode.txt

$ ls
*아무것도 표시되지 않아야 함*
```

앞 과제에서 만든 파일을 `rm`으로 삭제한 뒤 _해킹_ 버튼을 누르세요.
