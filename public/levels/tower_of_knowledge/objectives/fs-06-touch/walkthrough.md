# 파일 만들기

명령줄이나 그래픽 파일 탐색기에서는 기존 파일을 찾고 여는 일이 많지만, 새 프로젝트의 파일 구조를 잡을 때는 명령줄에서 파일을 빠르게 만드는 편이 편리합니다. 다른 명령어의 결과를 담을 파일처럼 명령어 흐름의 일부로 파일을 만들 수도 있습니다.

PowerShell에서 새 파일을 만드는 명령어는 `ni`입니다. `ni yourfilename.txt`처럼 뒤에 파일 이름을 적습니다. `ni`는 "new item"의 약자로 파일과 폴더를 만들 수 있으며, 기본적으로 파일을 만듭니다.

## PowerShell 별칭

앞 과제에서 폴더를 만들 때 쓴 `mkdir`도 PowerShell에서는 `ni -ItemType Directory`의 별칭입니다. PowerShell은 Windows와 Linux를 오가는 사용자를 위해 bash 같은 Linux 셸 명령어의 별칭을 제공합니다. 이미 `cd`와 `ls`도 사용했습니다. 다만 `touch` 별칭은 없으므로 파일을 만들 때는 `ni`를 사용합니다.

## 파일 속성

`ni`로 파일을 만들면 `Mode`, `LastWriteTime`, `Length`가 표시됩니다. `Length`는 파일 크기이고 `LastWriteTime`은 마지막 수정 시각입니다. 비슷한 파일이 많을 때 최근 작업 파일을 찾거나 `git` 같은 개발 도구가 변경을 판단할 때 사용합니다.

`Mode`는 파일 속성을 여섯 글자 플래그로 나타냅니다. 꺼진 옵션은 `-`로 표시됩니다.

- `d`: **디렉터리**
- `a`: **보관 가능**
- `r`: **읽기 전용**
- `h`: **숨김**
- `s`: 운영체제에 필요할 수 있는 **시스템** 파일
- `l`: 다른 파일을 가리키는 심볼릭 링크 등이 될 수 있는 **재분석 지점**

폴더 모드는 `d-----`, 읽기 전용 파일은 `--r---`처럼 표시됩니다. 파일을 수정할 수 없다면 읽기 전용 속성 때문일 수 있습니다.

새 파일을 만드는 여러 방법 중 `touch`가 널리 쓰이고 편리합니다. `touch yourfilename.txt`처럼 파일 이름을 적으면, 파일이 없을 때 그 이름의 빈 파일을 만듭니다.

## 파일 속성

`touch`는 빈 파일을 만들 뿐 아니라 파일의 수정·접근 시각도 설정합니다. 이 타임스탬프는 비슷한 파일 가운데 최근 작업한 것을 찾거나 `git` 같은 개발 도구가 변경을 판단할 때 사용합니다.

`ls -l`을 사용하면 다른 속성도 볼 수 있습니다. `-l`은 추가 정보를 표시하는 긴 형식 플래그입니다. 첫 열에는 다음 파일 권한이 표시됩니다.

- `r`: 파일 내용을 읽는 권한
- `w`: 파일 내용을 바꾸는 권한
- `x`: 파일을 스크립트나 프로그램으로 실행하는 권한

권한은 항상 `rwx` 순서이며 꺼진 권한은 `-`로 바뀝니다. `ls -l`에서는 파일 소유자, 같은 컴퓨터의 사용자 그룹, 그 밖의 사용자에 대한 세 묶음이 표시되어 최대 아홉 글자가 됩니다. `chmod` 같은 명령어로 바꿀 수 있습니다. 파일을 수정할 수 없다면 권한 설정 때문일 수 있습니다.
