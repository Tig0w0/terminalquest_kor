# 작업 디렉터리

그래픽 인터페이스에 익숙하다면 "작업 디렉터리"라는 개념이 낯설 수 있습니다. 그래픽 환경에서는 보통 애플리케이션을 여는 작업 공간인 바탕 화면에서 작업합니다. 디렉터리는 파일 탐색기로 파일을 찾거나 애플리케이션에서 파일을 열 때 주로 의식하게 됩니다.

터미널에서는 바탕 화면도 파일을 담는 평범한 디렉터리일 뿐이며, 터미널을 처음 열었을 때 시작하는 위치도 대개 바탕 화면이 아닙니다. 처음에는 해당 컴퓨터의 사용자 계정에 속한 "홈 디렉터리"에 있게 됩니다.

터미널에서 명령어를 실행하는 일은 바탕 화면에서 애플리케이션을 시작하는 것과 같습니다. 메뉴나 도구 모음의 아이콘을 클릭하는 대신 명령어를 입력하여 프로그램을 시작합니다.

일부 프로그램은 어느 디렉터리에서 실행되었는지를 중요하게 여깁니다. 예를 들어 상대 경로로 파일을 찾을 때 이 정보를 사용합니다. 파일을 만들거나 삭제하는 명령어라면 특히 중요합니다! 이를 프로그램의 "작업 디렉터리"라고 하며, 보통 명령어를 실행할 당시 터미널에서 위치한 디렉터리로 설정됩니다.

`pwd`는 터미널에서 연 "현재 작업 디렉터리"를 알려 줍니다. 디렉터리의 파일 경로가 필요할 때 유용합니다. JavaScript 테스트 연구소와 Python 사원에서는 미션 코드를 보관할 디렉터리 경로를 입력해야 하는데, `pwd`로 쉽게 얻을 수 있습니다. 무엇보다 파일 시스템에서 현재 어디에 있는지 항상 확인할 수 있습니다.

## 왜 `pwd`가 필요한가요?

"터미널이 명령어 앞에 현재 디렉터리를 표시하는데 왜 `pwd`가 필요하지?"라고 생각할 수 있습니다.

그 텍스트를 프롬프트라고 합니다. 프롬프트는 터미널이 명령어 같은 새 입력을 받을 준비가 되었음을 나타냅니다. 유용한 정보가 많이 담길 수 있으며, 기본 설정에서는 `pwd`를 입력한 것처럼 현재 작업 디렉터리를 보여 주는 경우가 많습니다.

코딩과 터미널에 익숙해지면 프롬프트에 다른 정보를 표시하도록 꾸밀 수도 있습니다. 아무 정보도 표시하지 않는 "미니멀" 터미널을 선호할 수도 있지요. 따라서 프롬프트에 의존하지 않고 현재 작업 디렉터리의 전체 경로를 표시하는 방법을 알아 두면 언제나 유용합니다.

스크립트에서도 자주 사용합니다. 텍스트 인터페이스는 여러 명령어를 조합해 복잡한 작업을 수행하는 작은 프로그램을 쉽게 만들 수 있다는 장점이 있습니다. 작업 디렉터리를 다른 명령어에 전달해야 할 때 `pwd`를 사용하면 스크립트에서 이를 자동화할 수 있습니다.
