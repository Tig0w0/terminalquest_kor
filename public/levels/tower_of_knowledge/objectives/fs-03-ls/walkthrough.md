# 디렉터리 내용 나열하기

`ls`는 현재 디렉터리의 파일과 디렉터리를 모두 나열합니다. 터미널에서 `ls`를 실행하고 표시된 파일이나 디렉터리 중 하나를 입력하세요.

<% if(isWindows) { %>

기본 출력만으로는 어느 항목이 파일이고 디렉터리인지 바로 알기 어렵습니다. `-`로 시작하는 옵션인 "플래그"를 `ls`에 전달하면 특정 종류만 볼 수 있습니다. 디렉터리만 보려면 `ls -Directory`, 파일만 보려면 `ls -File`을 사용하세요.

> ⚠️ PowerShell에서 `ls`는 `Get-ChildItem` 명령어의 별칭입니다. Linux와 Mac에도 `ls`가 있지만 서로 다르게 작동할 수 있습니다. PowerShell의 `ls`는 실제로 `Get-ChildItem`이라는 점을 운영체제를 오갈 때 기억하세요.

<% } else { %>

`ls`는 이름 외에도 크기, 읽기·쓰기 권한, 마지막 수정 시간 같은 정보를 보여 줄 수 있습니다. `-`로 시작하는 옵션인 "플래그"를 전달하면 됩니다. `ls -F`에서 `-F`는 "classify" 플래그이며 각 이름에 표시를 붙여 디렉터리인지 다른 종류의 파일인지 구분해 줍니다.

<% } %>
