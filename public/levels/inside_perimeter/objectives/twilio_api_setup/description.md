# 진실의 석상 통과하기

지하 묘지의 과제처럼 Twilio API를 사용하는 프로그래밍 과제를 수행하려면 Twilio 계정이 필요합니다. [Twilio 계정을 만든 뒤](https://www.twilio.com/try-twilio?utm_source=twilioquest-3), **Account SID**와 **Auth Token**이라고 부르는 API 인증 정보를 찾으세요. 이 인증 정보는 [Console 홈 페이지](https://www.twilio.com/console)에서 확인할 수 있습니다.

오른쪽 입력란에 두 값을 입력하고 *HACK* 버튼을 누르세요. 인증 정보가 유효한지 검사한 뒤 앞으로의 Twilio 관련 과제에서 사용할 수 있도록 TwilioQuest에 저장합니다.
